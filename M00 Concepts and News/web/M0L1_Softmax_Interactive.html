The Softmax Function

From Boltzmann's statistical mechanics (1868) to modern neural networks (1989), discover how the softmax function transforms raw scores into probability distributions.

Historical Evolution

1868

Ludwig Boltzmann

Introduced the Boltzmann distribution in statistical mechanics:

$$P(i) = \frac{e^{-E_i / kT}}{\sum_{j} e^{-E_j / kT}}$$
1959

R. Duncan Luce

Luce's Choice Axiom - probabilistic choice behavior

1989

John S. Bridle

Formally introduced "Softmax" to neural networks for pattern classification

2017

Vaswani et al.

"Attention Is All You Need" - Softmax in Transformer attention mechanism

Mathematical Formulation

Standard Softmax

$$\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{n} e^{z_j}}$$

Properties

  • ✓ Range: (0, 1)
  • ✓ Sum equals 1
  • ✓ Monotonic
  • ✓ Differentiable

Numerically Stable Version

$$\text{Softmax}(z_i) = \frac{e^{z_i - \max(\mathbf{z})}}{\sum_{j=1}^{n} e^{z_j - \max(\mathbf{z})}}$$

Why Subtract Max?

Prevents numerical overflow when $e^{z_i}$ becomes too large. The subtraction doesn't change the result but keeps values in a safe range.

Applications in Large Language Models

1. Attention Mechanism

Softmax converts attention scores into attention weights:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

2. Token Prediction

Final layer converts logits to token probabilities:

$$P(\text{token}_i | \text{context}) = \frac{e^{z_i}}{\sum_{j=1}^{|V|} e^{z_j}}$$

Computational Complexity

Time Complexity

O(n) for n tokens

Space Complexity

O(n) for storage

Optimization

GPU vectorization, fused kernels

Key Takeaways

✓ Softmax evolved from Boltzmann (1868) to Bridle (1989)

✓ Converts logits to valid probability distributions

✓ Always subtract max for numerical stability

✓ Critical for attention and token prediction in LLMs

✓ Differentiable - enables gradient-based learning

✓ O(n) complexity - efficient for large vocabularies
